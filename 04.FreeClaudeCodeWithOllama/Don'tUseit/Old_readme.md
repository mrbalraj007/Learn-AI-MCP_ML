Step-by-Step Installation & Setup
Step 1: Install Visual Studio Code
VS Code is required as the main development environment.

Go to the official VS Code website
Download the version for your OS (Windows / macOS / Linux)
Install and launch VS Code

✅ Purpose: Write, edit, and preview code generated by AI

Step 2: Install Node.js
Claude Code is built using JavaScript and needs Node.js to run.

Visit the official Node.js website
Download the MSI installer (Windows) or equivalent for your OS
Install Node.js
Verify installation:
Shellnode -vnpm -vShow more lines


✅ Purpose: Enables Claude Code installation and execution

Step 3: Install Ollama
Ollama allows AI models to connect with Claude Code.

Visit ollama.com
Download the app for your operating system
Install and launch Ollama

✅ Purpose: Acts as middleware between Claude Code and AI models

Step 4: Create & Sign In to an Ollama Account

Open Ollama
Go to Settings
Click Sign In
Complete login in the browser

✅ Important Note:
Ollama account creation is completely free

Step 5: Install Claude Code (CLI)
There are two methods:
Method 1: Using Terminal (Recommended)

Open Windows PowerShell or Terminal
Visit claude.ai/code
Copy the CLI install command
Paste and run it in the terminal

Example:
Shellnpm install -g @anthropic-ai/claude-codeShow more lines
✅ Claude Code gets installed globally

Step 6: Verify Claude Code Installation
Run:
Shellclaude --versionShow more lines
✅ If installed correctly, version information will appear
Example:
Claude Code v2.1.80


Step 7: Install Claude Code VS Code Extension

Open VS Code
Go to Extensions
Search for Claude Code
Install the official extension

✅ Enables Claude Code interaction directly in VS Code

Connecting Claude Code with Ollama & Minimax
Step 8: Choose AI Model (Minimax M2.7)

Open Ollama Dashboard
Go to Models
Select Minimax M2.7
Copy the launch command for Claude Code

Important details:

Model is cloud-hosted
No local storage needed
No GPU required


Step 9: Launch Claude Code with Ollama
In VS Code terminal:
