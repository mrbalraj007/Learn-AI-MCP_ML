
# Terraform MCP Server with Claude Code

## Overview
This document explains how to set up and use the **official Terraform Model Context Protocol (MCP) Server** with **Claude Code** (or any MCP-compatible LLM). The goal is to solve a common and costly problem in Terraform workflows: **inaccurate or hallucinated provider arguments generated by AI models trained on stale data**.

By integrating the Terraform MCP Server, the LLM no longer relies purely on historical training data. Instead, it queries the **live Terraform Registry and provider schemas in real time**, producing Terraform code that matches the current provider documentation.


This README is written as a practical, step-by-step technical guide based on real usage and observed behavior.

---

## Problem Statement
When using AI tools like Claude Code to generate Terraform:

- Provider arguments may be outdated
- Required attributes may be missing
- Deprecated or invalid fields may appear
- Terraform plans fail even for simple resources

### Why This Happens
LLMs are trained on historical snapshots of Terraform providers. As providers evolve, schemas change, but the model’s knowledge does not automatically update.


The result: Terraform code that looks correct but fails at runtime.

---

## Solution: Terraform MCP Server

- The **Terraform MCP Server** acts as a live bridge between your AI coding assistant and:

  - Terraform Registry
  - Current provider schemas
  - Resource input/output definitions
  - Terraform Cloud / Enterprise (optional)
- Instead of guessing, the LLM queries real provider data at generation time

## Step-by-Step Setup

### 1. Authenticate with Terraform

```bash
terraform login
```

Copy the generated API token.

### 2. Pull Terraform MCP Server

```bash
docker pull hashicorp/terraform-mcp-server
```

### 3. Configure MCP in Claude Code

- Add a new MCP server
- Run locally via Docker
- Provide Terraform address and API token



Step 3: Add the MCP Server to Claude Code
In Claude Code (or your MCP-compatible tool):

Open MCP configuration
Add a new MCP server
Configure it to run locally via Docker
Provide: Terraform address: app.terraform.io
Terraform API token
The MCP server will start as a local container and register itself with Claude.

### 4. Verify Connection

Ensure Terraform appears as an active MCP provider.


Once connected, you should see:

Terraform listed as an active MCP
Successful handshake with no errors

A restart of the AI client may be required.



### 5. Run Terraform Plan

```bash
terraform plan
```

Fix failures using MCP-powered prompts.
